# Recette d'une modification backend

Vérifier une requête valide, un corps invalide et un appel sans autorisation. Pour une route qui vise une ressource utilisateur, ajouter un cas avec une autre session. Pour une mutation, vérifier l'état persistant après un échec puis après une requête répétée. Quand deux appels peuvent viser la même ressource, reproduire ce cas sur une base de test.

Reporter dans la référence les changements de méthode, de droits, d'entrée ou de réponse. Pour une modification de schéma, joindre le résultat de la [recette sur les données existantes](../donnees/evolution.md).
